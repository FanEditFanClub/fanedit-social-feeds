# fanedit-social-feeds

Public JSON feeds for the Fan Edit Fan Club website widgets, refreshed every 30 min.

- `x-posts.json` — latest @FanEditFanClub X posts (via Buffer)
- `reddit-community.json` — latest r/FanEditFanClub posts (via Reddit public RSS, no credentials needed)
- `reddit-multireddit.json` — latest posts from the club multireddit feed (via Reddit public RSS)
